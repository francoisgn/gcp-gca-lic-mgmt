# Configuration

Three layers, from the most stable to the most specific:

```
config/*.yaml (git, pull request)  ──▶  environment variables (Terraform)  ──▶  Secret Manager (values never in git)
```

**Precedence**: environment variable > YAML file > built-in default. Every file is decoded **strictly**: an unknown key stops the process at start-up (typos never go unnoticed).

## YAML files (versioned)

| File | Content | Change process |
|---|---|---|
| `config/roles.yaml` | `super_admins`, `admins` (e-mails) | pull request + redeploy |
| `config/policy.yaml` | business rules: durations, `unused_days` (7), `buffer_max_attempts` (30), external accounts, eligibility, monthly directory re-check, e-mail notifications, questions of step D, links | pull request + redeploy |
| `config/settings.yaml` | **production integrations**: enterprise directory, GitLab / Jira, SMTP — connection details only | pull request + redeploy |
| `config/settings.dev.yaml` | local integrations (everything simulated / logged) | — |

The settings file is chosen by `SETTINGS_FILE`; default `config/settings.dev.yaml`, or `config/settings.yaml` when `APP_ENV=prod`. Terraform sets `SETTINGS_FILE=/app/config/settings.yaml`.

### `settings.yaml` — integrations

```yaml
directory:
  mode: http                      # http | simulated
  base_url: https://directory.example.com/api
  timeout: 5s
  lookup:
    path: /v1/accounts            # or /v1/accounts/{email}
    email_param: email            # query parameter when the path has no {email}
  auth:
    type: bearer                  # bearer | header | none
    header: Authorization         # header name when type = header (e.g. X-API-Key)
    secret_env: DIRECTORY_API_KEY # env var filled from Secret Manager
  fields:                         # JSON fields of the answer (dotted paths allowed)
    status: status
    site: site
    business_unit: businessUnit
    gps_code: gpsCode

tracker:
  mode: gitlab                    # gitlab | jira | log
  gitlab:
    base_url: https://gitlab.example.com
    project: platform/gca-license-portal
    labels: [gca-portal, feedback]
    token_secret_env: GITLAB_TOKEN

mail:
  mode: smtp                      # smtp | log
  from: gca-portal@example.com
  smtp: { host: smtp-relay.gmail.com, port: 587, user: "", password_secret_env: SMTP_PASSWORD }
```

**Secrets rule**: a `*_secret_env` key holds the **name** of an environment variable, never a value. Cloud Run fills that variable from Secret Manager:

| `*_secret_env` value | Secret Manager secret | Content |
|---|---|---|
| `DIRECTORY_API_KEY` | `gcalm-directory-api-key` | directory API key / token |
| `GITLAB_TOKEN` (or Jira token) | `gcalm-tracker-token` | technical account token (GitLab scope `api`) |
| `SMTP_PASSWORD` | `gcalm-smtp-password` | empty when the relay authorizes by IP / domain |
| — | `gcalm-database-url` | generated by Terraform |

Renaming a variable = change `secret_env` in the YAML **and** the `secret_env` map in `deploy/terraform/run.tf`.

### `policy.yaml` — business rules (extract)

```yaml
accounts:
  external_suffix: ".ext"         # firstname.lastname.ext@domain = external: never auto-approved

eligibility:
  account_statuses: ["OK"]
  gps_code_pattern: "^[0-9a-fA-F]{8}$"
  allowed_business_units: []      # empty = any
  # GPS codes allowed for auto-approval: database table, Admin → GPS codes

directory_recheck:
  enabled: true
  max_per_run: 2000               # licenses checked per night at most
  concurrency: 4                  # parallel directory calls

notifications:                    # false = e-mail not sent (still journaled as DISABLED)
  request_escalated: true
  admin_new_escalation: true
  # … see the Notifications page
```

## Environment variables

| Variable | Default | Description |
|---|---|---|
| `APP_MODE` | `all` | `web` (portal), `worker` (HTTP job endpoints, alternative to Cloud Run jobs), `all` (dev). Cloud Run jobs run `gcalm job <name>` (one run, then exit). |
| `APP_ENV` | `dev` | `prod` forbids dev authentication and demo data, selects `settings.yaml` |
| `SETTINGS_FILE` | see above | integration settings file |
| `ROLES_FILE` / `POLICY_FILE` | `config/…` | |
| `PORT` | `8080` | |
| `BASE_URL` | `http://localhost:8080` | portal URL used in e-mails |
| `TIMEZONE` | `Europe/Paris` | dates, per-day KPIs, anniversary of the directory re-check |
| `DATABASE_URL` | local | PostgreSQL DSN (Cloud Run: unix socket `/cloudsql/...`) — **secret** |
| `AUTH_MODE` | `dev` | `iap` in production |
| `IAP_AUDIENCE` | | `/projects/NUMBER/locations/REGION/services/gcalm-web` |
| `DEV_DEFAULT_USER` | `jane.doe@example.com` | identity when no dev cookie |
| `GOOGLE_MODE` | `fake` | `real` = Procurement API |
| `BILLING_ACCOUNT_ID` | | billing account holding the orders |
| `QUOTA_PROJECT` | | project billed for API quota |
| `GCA_ORDER_MATCH` | `(?i)gemini\|code ?assist\|cloudaicompanion` | regex identifying GCA orders (offer + display name) |
| `GCA_ORDER_IDS` | | explicit comma-separated order IDs (bypass the regex) |
| `GCA_PROJECT_ID` | | project users select in the IDE (e-mail) |
| `CREDENTIALS_MODE` | `fake` | `group` (Cloud Identity), `none` (roles granted elsewhere) |
| `CREDENTIALS_GROUP` | | e-mail of the IAM bundle group |
| `UX_TIMEOUT` | `10s` | budget of steps 7 + 8 (credentials + license) when the user waits |
| `JOB_CALL_TIMEOUT` | `30s` | per call in jobs and admin actions |
| `POOL_CACHE_TTL` | `60s` | Google pool snapshot cache |
| `RATE_LIMIT_PER_MIN` / `RATE_LIMIT_BURST` | `120` / `30` | per user |
| `METRICS_RETENTION` | `240h` | technical KPIs retention |
| `BUFFER_RETRY_EVERY` | `7m` | displayed to users (the real schedule is Cloud Scheduler's) |
| `INPROCESS_SCHEDULER` | `false` | run jobs on tickers (dev) |
| `JOBS_AUDIENCE` / `JOBS_INVOKER` | | re-verify scheduler OIDC tokens |
| `LOG_LEVEL` | `info` | `debug` logs every outbound call |
| Dev only: `DEMO_SEED`, `FAKE_GOOGLE_STATE_FILE`, `FAKE_GOOGLE_SEATS`, `FAKE_GOOGLE_MAX_LATENCY`, `FAKE_GOOGLE_HANG_RATE`, `DIRECTORY_SIM_FAILURE_RATE`, `DIRECTORY_SIM_MAX_LATENCY` | | simulators |

### Overrides of `settings.yaml` (optional)

Useful for docker compose or a one-off test; production should rely on the YAML.

| Variable | Overrides |
|---|---|
| `DIRECTORY_MODE`, `DIRECTORY_URL`, `DIRECTORY_TIMEOUT`, `DIRECTORY_LOOKUP_PATH`, `DIRECTORY_AUTH_TYPE` | `directory.*` |
| `MAIL_MODE`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `MAIL_FROM` | `mail.*` |
| `TRACKER_MODE`, `GITLAB_URL`, `GITLAB_PROJECT`, `JIRA_URL`, `JIRA_USER`, `JIRA_PROJECT`, `JIRA_ISSUE_TYPE` | `tracker.*` |

Invalid combinations stop the process at start-up with an explicit message (e.g. `directory.mode: http` without the API key variable, unknown `auth.type`).
