Set up Gemini Code Assist in VS Code
  1. Install the Gemini Code Assist extension (publisher: Google) from the VS Code Marketplace.
  2. Click the Gemini Code Assist icon in the activity bar, then Sign in with Google with your company account.
  3. When prompted, select the Google Cloud project given in your confirmation e-mail.
  4. Open a file and start coding: completions appear inline, the chat is in the side panel.
